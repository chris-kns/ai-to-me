# Exercícios

Cada conceito precisa virar código. Terminou o conceito? Ganhe um **problema** (lista), um **exercício de modelagem** (dicionário) ou um **cenário** (função).

## Padrão de um exercício

1. **Problema ou cenário** (curto, realista, de infraestrutura ou do projeto)
2. **Critérios de aceite** (como eu sei que terminei)
3. **Pergunta "por quê?"** (a decisão que preciso saber defender)
4. **Sem solução no arquivo.** Se quiser guardar a sua, coloque em `solucoes/` do seu repositório de código, não aqui.

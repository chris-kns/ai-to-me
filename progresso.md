# Progresso

> Painel de acompanhamento. O checklist de cada semana fica nos arquivos de [plano/](plano/README.md); aqui ficam os **marcos** e os **números** que mostram se o método está funcionando.

## Marcos

### Fase 1: Base DevOps/SRE
- [ ] Mini projeto em Python funcionando (Semana 1)
- [ ] Projeto pequeno com estrutura, testes, `.git` e README (Semana 2)
- [ ] Pipeline de CI verde + imagem Docker (Semana 3)
- [ ] Stack de monitoramento rodando + repositório base da API de inventário (Semana 4)

### Fase 2: Fundamentos de Backend
- [ ] Contrato da API de inventário documentado (Semana 5)
- [ ] Banco modelado, com dados e 10 consultas úteis (Semana 6)
- [ ] CRUD em memória + modelagem do agendamento (Semana 7)
- [ ] API no PostgreSQL + **double booking reproduzido e impedido** + ADR (Semana 8)

### Fase 3: Backend profissional
- [ ] Autenticação JWT com RBAC (Semana 9)
- [ ] Cobertura ≥ 70%, teste de concorrência e CI verde (Semana 10)
- [ ] Cache e worker de fila, **cada um justificado por um problema real** (Semana 11)
- [ ] Logs, métricas, tracing, SLO e alerta (Semana 12)

### Fase 4: Arquitetura, deploy e mercado
- [ ] Diagrama de arquitetura + ADRs (Semana 13)
- [ ] API no cluster de laboratório com atualização automatizada (Semana 14)
- [ ] 10 problemas, 1 system design e pontos fracos mapeados (Semana 15)
- [ ] Portfólio publicado, currículo atualizado e primeiras candidaturas (Semana 16)

## Como ler os números

- **Proporção conteúdo : código** abaixo de 1:1 por duas semanas seguidas? Você está assistindo mais do que construindo. Corte conteúdo.
- **Autoteste** falhando sempre no mesmo tipo (conceito, prática ou decisão)? Veja [pontos-fracos.md](flashcards/pontos-fracos.md) e ajuste como estuda.
- **ADRs** zerados por 3 semanas? O projeto não está gerando decisões. Releia o mantra 4.
- **Vagas e candidaturas** zeradas depois da Semana 5? Mercado não é "depois". Veja [mercado/](mercado/README.md).
